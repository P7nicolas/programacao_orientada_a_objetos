# Introdução
Projeto desenvolvido para a disciplina de Programação Orientada a Objetos, com foco em aplicar os princípios da POO na criação de um jogo interativo em JavaScript.

Mistérios da Mansão é um jogo de aventura baseado em texto, no qual o jogador deve explorar salas, coletar e utilizar ferramentas, interagir com objetos e desvendar pistas para encontrar um diamante escondido. Cada escolha feita pode levar à vitória ou à derrota, exigindo raciocínio e estratégia.

# Estrutura do Projeto
•  **Engine** : Responsável por controlar o fluxo do jogo, salas, inventário e comandos.

•  **Salas** : Ambientes interativos que contêm objetos e ferramentas:

      • Hall de Entrada
      • Sala de Estar
      • Quarto
      • Cozinha
      • Biblioteca 
      • Sala Secreta

•  **Objetos Interativos** :

      • Gaveta
      • Armário
      • Bilhete
      • Pote de Arroz
      • Pote de Açúcar 
      • Cofre

•  **Ferramentas** :

      • Chave
      • Martelo 
      • Lanterna

•  **Comandos Disponíveis** :

      • pega [ferramenta]
      • usa [objeto]
      • remove [ferramenta]
      • sai [sala] 
      • inventário
      • fim

# Tecnologias Utilizadas
•  **JavaScript** : Lógica do jogo e estrutura orientada a objetos.

•  **Node.js** : Execução do jogo via terminal.
